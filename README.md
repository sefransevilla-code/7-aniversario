# 7 Aniversario ❤️

Una pequeña sorpresa para celebrar siete años de matrimonio.

## Contenido
- `index.html`: Página principal
- `images/`: Fotografías
- `musica.mp3`: Canción

## Cómo usar

1. **Localmente**: Abre `index.html` en tu navegador
2. **En línea**: La página está disponible en GitHub Pages

## Instrucciones
- Pulsa el botón "Música" para activar la canción
- Haz clic en cualquier foto para ampliarla
- Desplázate para ver toda la historia

## Nota
La canción se incluye como archivo local. Si publicar públicamente, asegúrate de tener permiso para distribuir/reproducir la grabación en la web.
